# Design: Backend 03 — AI Topic Clustering & Grounded Question Generation

## 1. Modules & Structure
- `app/ai/schemas.py`: Pydantic models for structured question banks, options, and citations.
- `app/ai/gemini.py`: Question generation methods invoking Gemini 1.5 Flash.
- `app/api/dungeons.py`: Endpoints for topic preview, dungeon generation, and room layouts.
- `app/models/all_models.py`: `Topic`, `Question`, `Dungeon`, `DungeonRoom`.

## 2. Ingestion-Time Generation & Citation Rules
1. **Topic Extraction:**
   - Ingested document chunks are aggregated.
   - AI identifies 2 to 6 coherent topics (e.g., "CPU Architecture", "Memory Hierarchy").
   - Chunks are associated with topics in PostgreSQL.
2. **Grounded Question Generation:**
   - 5 to 8 MCQs/TF generated per topic room.
   - **Mandatory Substring Verification:** Every generated question MUST include an `evidence_quote`.
   - The backend deterministically asserts `evidence_quote.strip().lower() in source_chunk.text.lower()`.
   - If a quote does not appear verbatim in the cited chunk, the question is flagged and rejected to eliminate hallucination.
3. **Zero Combat Invocations:**
   - All questions, distractors, correct answers, and explanations are saved to PostgreSQL during ingestion.
   - Combat lookups are pure relational queries.

## 3. Endpoints & Data Flow
- `GET /documents/{id}/topics`: Returns identified topics and chunk counts.
- `POST /documents/{id}/generate-dungeon`: Creates `Dungeon`, creates `DungeonRoom` for each topic, populates `Question` bank. Guests blocked with `403`.
- `GET /dungeons`: Lists dungeons owned by user + the public seeded demo dungeon.
- `GET /dungeons/{id}`: Returns dungeon metadata, room order, monster types, and question prompts (answers withheld).

## 4. Implementation Status
- **Implemented:**
  - `Topic`, `Question`, `Dungeon`, and `DungeonRoom` SQLAlchemy models.
  - Pydantic models in `app/ai/schemas.py`.
- **Missing / Pending:**
  - Gemini topic extraction prompt implementation.
  - Gemini grounded question generation prompt with Pydantic JSON schema mode.
  - Verbatim citation substring verification logic.
  - `POST /documents/{id}/generate-dungeon`, `GET /dungeons`, `GET /dungeons/{id}` route handlers.

## 5. Test Strategy & Property-Based Testing
- **Property-Based Testing (PBT Candidate):**
  - **Evidence Quote Invariant:** For every accepted `Question` generated by the pipeline, `assert question.evidence_quote in chunk.text` must hold true under arbitrary chunk texts.
  - Hypothesized fuzz testing ensuring malformed AI output (missing options, out-of-bound `correct_option`) never corrupts the database.
